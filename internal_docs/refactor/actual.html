Broken Wires — Critical Issues to Fix

CRITICAL

suppliers:update handler ignores SupplierUpdateInput

src/main/ipc/suppliers.ts:13
Handler signature: (supplierId, newName) → calls renameSupplier(supplierId, newName)
Actual call from frontend: update(supplierName, { supplierInfo: {...} })
Impact: All supplier info edits, parent name assignments, and categoryA toggles silently fail. [object Object] set as supplier name in DB.
  • supplier info edits (type, name, industry, NAICS, etc.) — lost
  • parent company name assignments — lost
  • categoryA toggle — lost

Fix: Implement updateProjectSupplier(id: string, updates: SupplierUpdateInput) in SupplierService. Update handler to call it. Update DB schema to add category_a column to project_suppliers.

CRITICAL

listProjectSuppliers returns stub data

src/main/services/supplier-service.ts:164–179
supplierInfo: null, categoryA: false, aliases: [] always.
Data from SupplierUniverse never joined or fetched. SuppliersPage shows empty info columns for all suppliers.
  • Supplier type, NAICS, industry, products — always blank
  • Aliases — always empty array
  • categoryA — always false, can't be stored (no DB column)

Fix: Add category_a column to project_suppliers schema. Join with supplier_universe.db to pull supplier_info and aliases in listProjectSuppliers(). Or fetch from universe via enrichProjectSupplier after research.

CRITICAL

WorkflowStore missing 8 state fields

src/renderer/stores/workflowStore.ts
Spec defines rich derived state for sidebar step gating. Actual store is minimal — only hasProject + isClassifying.
  • No hasCompanyContext — company context step can't show as complete
  • No hasTaxonomy — taxonomy step indicator broken
  • No hasUploadedData — upload gate not set from store
  • No hasReviewedData / dataReviewed — DataReview gate missing
  • No hasClassifiedData — Review step gating incomplete
  • No uploadDraft — upload state lost on navigation
  • No reviewFilters — Review filter state not persisted
  • No WorkflowStateContext — Sidebar reads directly from Zustand (works, but tighter coupling)

Fix: Add missing fields + actions. Derive booleans from projectMetadata.companyContext, taxonomyNodeCount, stats data. Call transactions:stats and taxonomy:getNodeCount on metadata refresh to populate them.

MODERATE

New transaction IPC methods cast to concrete class

src/main/ipc/transactions.ts:23–50
queryGroupedByColumn, queryDistinctValues, getTransactionIdsByColumnValue, queryPivotAggregation are not on the TransactionStore interface. Handlers cast transactions as import('../services/transactions').TransactionStore to access them.

Fix: Add the 4 methods to TransactionStore interface in src/shared/types/services.ts. Remove concrete class casts.
